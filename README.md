# wiki-interest-research

Навичка (Agent Skill) для AI-агента: вимірює, як змінюється публічний інтерес до теми в різних
мовних розділах Вікіпедії за статистикою переглядів Wikimedia, оцінює, **наскільки цьому тренду
можна довіряти**, і будує графіки та PDF-звіт на одну сторінку.

Ключовий принцип: **усі числа рахує код, а агент лише обирає статті, запускає команди й пояснює
результат** — тому навичкою може впевнено користуватися навіть швидка недорога модель.

> **Статус: у розробці.** Репозиторій наповнюється поетапно; зараз доступна лише команда `doctor`.

## Вимоги

- Node.js 20.10 або новіший
- доступ до `wikimedia.org` і `wikidata.org`

## Швидкий старт

```bash
npm ci
npm run doctor
```

## Структура

```
wiki-interest-research/
├── SKILL.md            інструкція для агента (name, description, процес)
├── scripts/wiki.mjs    точка входу: запускає TypeScript через tsx, без збірки
├── src/                код навички
├── package.json        залежності та команди
└── tsconfig.json       строгі налаштування TypeScript
```
